# 경제나무

경제 지식이 거의 없는 성인을 위한 자산 증식 개념 학습 사이트. `index.html` 하나로 동작합니다 (브라우저로 열면 끝).

## 구성
- **용어 5층**: 1 원리 → 2 상품 → 3 세금·제도 → 4 위험관리 → 5 파생. 위층 용어에는 "먼저 알아야 할 하위 개념"이 표시됨. 5층은 한 문단 미리보기 제공.
- **12주 로드맵**: 주차별 핵심 3개 + 직접 해볼 것 1개, 주차 완료 체크.
- **1층 전체**: 단리·복리·72의 법칙·인플레이션·실질수익률. 퀴즈를 먼저 풀어야 설명이 열림.
- **복리 계산기**: 원금·수익률·기간(+복리 주기, 물가)으로 단리/복리/물가 반영 가치를 그래프로 비교.
- **오답 노트**: 틀린 문제만 다시 출제, 맞히면 자동 제거.
- 진도·오답·계산기 입력값은 `localStorage`에 저장.

## 콘텐츠 추가하기
파일 상단 `DATA` 객체만 수정하면 됩니다.
- `DATA.TERMS`에 용어 추가. `ready: true` + `quiz`, `body`, `later`, `onIncome`을 채우면 학습 페이지가 열림.
- 본문 표기: `[[용어|한 줄 풀이]]`(그 자리에서 풀어쓰기), `@@termId@@`(용어 링크), `{{calc}}`(계산기 삽입).
- 퀴즈 엔진 `QuizEngine`은 `register / mount / wrongIds` API로 다른 코너에서도 재사용 가능.
